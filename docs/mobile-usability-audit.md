# 모바일 사용성 점검 및 코드 검사 정리

## 이번 변경

기존 격자 배경, 미니홈피 프레임, 메뉴 색상, 사진 비율과 프로젝트 표는 유지한다.

| 수정 전 | 수정 후 | 영향 범위 |
| --- | --- | --- |
| 한 열의 모바일 프로젝트에도 두 카드 높이 맞춤 코드가 적용되어 빈 공간이 생김 | 모바일 카드에는 자연스러운 콘텐츠 높이 사용 | 모바일 프로젝트 목록 |
| 프로젝트 상세창에서 배경 조작과 키보드 초점 이탈 가능 | 배경을 inert 처리하고 스크롤 잠금, 초점 순환, Esc 닫기, 원래 카드로 초점 복귀 | PC·모바일 프로젝트 상세 |
| 프로젝트 카드를 키보드로 열 수 없고 이미지 설명이 없음 | Enter/Space로 열기, 이미지 대체 텍스트, 지연 로딩 | PC·모바일 프로젝트 목록 |
| 연락처 입력 제목이 div여서 입력칸과 연결되지 않음 | label 연결 및 이름·이메일 자동완성 힌트 | PC·모바일 연락처 |
| 작은 연락처 버튼과 긴 안내문 | 모바일 버튼 높이 최소 44px, 글자 16px, 안내문 글자·줄바꿈 조정 | 모바일 연락처 |
| 피드백 조회 실패가 전체 화면 오류 팝업을 띄움 | 해당 영역 안에서 오류 안내와 재시도 제공, 재조회 성공 시 오류 해제 | PC·모바일 피드백 |

## 코드 검사

기존 ESLint 오류 67건, 경고 4건을 정리했다.

- 사용하지 않는 import, 변수, 비활성 코드를 제거했다.
- JSX 인용부호를 엔티티로 바꾸되 표시 문구는 유지했다.
- 정규식의 불필요한 이스케이프를 제거했다.
- Skills의 위치 측정 함수를 effect 내부로 옮겨 누락된 의존성 경고를 해결했다.
- PC 프로젝트 높이 측정을 effect 내부로 옮겼고 모바일에서는 불필요한 높이 측정을 제거했다.
- React 버전을 18.3 고정값에서 실제 설치 버전 감지로 변경했다.
- `react/prop-types` 규칙은 비활성화했다. React 19는 propTypes 자동 검사를 지원하지 않는다. 관련 JavaScript 컴포넌트의 입력 구조는 JSDoc으로 명시했다. JSDoc은 문서화이며 이번 작업에서 별도 TypeScript 검사나 런타임 입력 검증을 추가한 것은 아니다.
- 다른 오류·Hooks 검사 규칙은 유지했다.

근거: [React 19 공식 업그레이드 안내](https://react.dev/blog/2024/04/25/react-19-upgrade-guide#removed-proptypes-and-defaultprops-for-functions)

## 검증

- `yarn lint`: 오류·경고 없음.
- `yarn build`: 성공. 기존 500kB 초과 번들 안내는 별도 성능 개선 후보다.
- Chrome 자동화: 모바일 360·390·760px, PC 1920px.
- 프로젝트 키보드 열기, 배경 조작 차단, 초점 순환, Esc 닫기, 초점·스크롤 위치 복원 확인.
- 연락처 label 클릭과 입력, 모바일 버튼 44px 이상, 입력칸의 화면 내 배치 확인.
- 피드백 조회 실패를 모의 응답으로 재현하고, 전체 팝업 없이 오류 안내 및 재시도 성공 확인.
- 실제 이메일이나 피드백을 전송하지 않았으며 테스트 중 해당 POST 요청이 없음을 확인.
- iPhone 실기기의 주소창·가상 키보드 동작은 이번 브라우저 크기별 검사와 구분하여 추가 확인이 필요하다.

## 후속 검토 후보

- 작은 PC 화면의 고정 최소 너비와 가로 넘침: 전체 배치에 영향이 있어 별도 시안 검토가 필요하다.
- 초기 JavaScript 번들 분리: 화면 변경 없이 가능한 성능 개선 후보이나 별도 로딩 회귀 검증이 필요하다.
